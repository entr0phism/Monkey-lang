# Writing an Interpreter in Go

This project is a direct implementation of the book _Writing an Interpreter in Go_ by Thorsten Ball.

## About

The goal of this project is to follow along with the book and build a simple interpreter from scratch using Go. It covers the core concepts behind interpreters, including:

- Lexing
- Parsing
- Abstract Syntax Trees (AST)
- Evaluation

## Status

Work in progress — following the book step by step.

## Reference

- Book: _Writing an Interpreter in Go_ by Thorsten Ball

## Notes

This is a learning project and sticks closely to the implementation described in the book, with minimal modifications.
